# deliverable-4-group5

Info about our project: 
The Product Expiration Tracker is a web app that helps grocery stores, bakeries, and cafés track product expiration dates. Employees log products when deliveries arrive, get daily alerts for items about to expire, and record discarded items. Managers set warning periods for each product category, approve sales and BOGO deals, and run expiration reports.

Technologies we will implement:
Frontend: React (JavaScript, HTML, CSS), works in any phone, tablet or computer browser
- Backend/API: Node.js with Express
- Database: PostgreSQL 15
- Containers: Docker and Docker Compose
- Hosting: AWS cloud (EC2 for the app, RDS for the database)
- Tools: GitHub, GitHub Projects, VS Code, DBeaver
